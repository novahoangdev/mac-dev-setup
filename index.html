Phần lõi của ~/.zshrcCore of ~/.zshrc

nvm được lazy-load để mở tab nhanh, nhưng Node mặc định vẫn có sẵn trong PATH cho script và agent. Mọi API key nằm trong ~/.zsh_secrets (chmod 600), không bao giờ viết thẳng vào .zshrc.nvm is lazy-loaded for fast tabs, while the default Node stays on PATH for scripts and agents. All API keys live in ~/.zsh_secrets (chmod 600), never inline in .zshrc.

export ZSH="$HOME/.oh-my-zsh"

[[ -f ~/.p10k.zsh ]] && source ~/.p10k.zsh

export BUN_INSTALL="$HOME/.bun"

# nvm: default Node on PATH now, full nvm only when called
export NVM_DIR="$HOME/.nvm"
_nvm_bin=(${~:-$NVM_DIR/versions/node/v$(<$NVM_DIR/alias/default 2>/dev/null)*/bin}(N-/nOn[1]))
(( ${#_nvm_bin} )) && export PATH="$_nvm_bin[1]:$PATH"; unset _nvm_bin
nvm() { unset -f nvm; source "$(brew --prefix nvm)/nvm.sh"; nvm "$@"; }

# secrets (API keys) — chmod 600, never committed
[ -r ~/.zsh_secrets ] && source ~/.zsh_secrets

OmniRoute — một endpoint cho mọi modelOmniRoute — one endpoint for every model

Gateway chuẩn OpenAI chạy local ở http://localhost:20128/v1: gom nhiều provider, tự fallback khi một model lỗi/hết quota. Tool nào nhận OPENAI_BASE_URL đều dùng được. Gateway nhìn thấy toàn bộ prompt và giữ key provider, nên chỉ chạy local.An OpenAI-compatible gateway at http://localhost:20128/v1: many providers behind one endpoint with automatic fallback. Any tool that honours OPENAI_BASE_URL can use it. It sees every prompt and holds provider keys, so keep it local.

npm i -g omniroute
omniroute            # open the dashboard, add providers, create an API key
# ~/.zsh_secrets
export OMNIROUTE_API_KEY="..."

# ~/.zshrc
alias om='nvm use 26 && omniroute'
alias oms='omniroute stop'
alias o='omp'
omp-omni() {
  OPENAI_API_KEY="$OMNIROUTE_API_KEY" \
  OPENAI_BASE_URL="http://localhost:20128/v1" \
  omp --model "${1:-antigravity/gemini-3.7-flash-low}"
}

Một bộ luật cho mọi agentOne rule set for every agent

AGENTS.md là nguồn chuẩn (Codex, Amp, Gemini, omp đọc trực tiếp). CLAUDE.md chỉ import nó. Skill dùng chung đặt ở .agents/skills/ và symlink sang .claude/skills/.AGENTS.md is the source of truth (Codex, Amp, Gemini and omp read it directly). CLAUDE.md just imports it. Shared skills live in .agents/skills/, symlinked into .claude/skills/.

my-repo/
├── AGENTS.md            # shared rules: fast path, verify, git safety
├── CLAUDE.md            # contains only: @AGENTS.md
├── .agents/skills/      # shared skills
└── .claude/skills -> ../.agents/skills
printf '@AGENTS.md\n' > CLAUDE.md
mkdir -p .agents/skills .claude && ln -s ../.agents/skills .claude/skills

Từ điện thoại: Tailscale + mosh + MoshiFrom a phone: Tailscale + mosh + Moshi

Tailscale tạo mạng riêng tới Mac (không mở port ra internet), mosh giữ kết nối khi đổi Wi-Fi/4G, moshi-hook đẩy yêu cầu duyệt quyền của agent về app Moshi trên điện thoại.Tailscale gives a private network to the Mac (no public ports), mosh survives Wi-Fi/cellular switches, and moshi-hook forwards agent permission prompts to the Moshi phone app.

sudo tailscale up
